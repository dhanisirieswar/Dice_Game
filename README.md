# Dicee Game 🎲

A simple two-player dice game built using HTML, CSS, and JavaScript.

## Features
- Generates random dice numbers for two players.
- Updates dice images dynamically.
- Compares both players' results.
- Displays the winner or a draw.
- Uses JavaScript DOM manipulation.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Refresh the page to roll the dice again.

## Concepts Practiced
- JavaScript variables
- Math.random() and Math.floor()
- DOM manipulation
- setAttribute()
- if, else if, and else conditions

## Project Purpose
Created as a beginner JavaScript project to practice DOM manipulation and basic programming logic.
